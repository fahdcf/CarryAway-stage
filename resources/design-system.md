# CarryAway Design System

This file documents the main colors, shapes, and design principles used in CarryAway Blade views. Use this as a reference for generating new designs and components.

## Typography
- Font: Segoe UI, Roboto, BlinkMacSystemFont, -apple-system, sans-serif
- Font weights: 400 (normal), 600 (semi-bold), 700 (bold)
- Titles: Large, bold, dark (#1e293b)
- Subtitles: Medium, muted (#64748b)
- Buttons: Medium, bold, clear contrast

## Shapes & Spacing
- Border radius: 8px (buttons), 16px (cards/modals)
- Card/modal padding: 1.5rem to 2.5rem
- Button padding: 0.5rem 1rem (normal), 0.375rem 0.75rem (small)
- Avatar: Circle, 40px
- Badge: Pill shape, 20px radius
- Shadows: Soft, subtle (0 4px 20px rgba(15,23,42,0.05) for cards)

## UI Components
- Cards: White background, rounded corners, subtle shadow
- Modals: Centered, rounded, shadow, clear header
- Buttons: Rounded, color-coded, hover transitions
- Badges: Pill-shaped, color-coded by status
- Tables: Striped, clean, clear headers
- Empty states: Centered icon, muted text

## Professional Style Principles
- Minimal, clean, modern
- Consistent spacing and alignment
- Clear color contrast for accessibility
- Smooth transitions for overlays/modals
- Responsive for mobile and desktop
